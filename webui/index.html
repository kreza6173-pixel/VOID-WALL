VirusTotal scan
Checks a file's SHA-256 hash against VirusTotal's database — fast, uses almost no quota, and works for any file size, but only finds a result if someone else has already scanned this exact file before. It never uploads the file itself (see the README for why). Your key is stored only in this browser unless you clear it.
